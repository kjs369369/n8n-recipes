04자주 묻는 질문

Q. JSON에 인증 정보가 포함되어 있나요?
A. 아닙니다. 모든 인증은 REPLACE_WITH_YOUR_* placeholder로 처리되어 있어, 안전하게 공유 가능합니다.

Q. 무료로 쓸 수 있나요?
A. n8n 셀프호스팅 + Gemini 무료 API + Vision API 월 1,000건 무료 한도 내에서 충분히 테스트 가능합니다.

Q. 워크플로가 작동하지 않습니다.
A. 가장 흔한 원인은 (1) Credential 미연결, (2) placeholder 값 미교체입니다. 책의 부록 A FAQ 섹션을 참조하세요.
